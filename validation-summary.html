Ethical and Data Privacy Considerations

Customer personal data is not collected — the system is built for in-store administrative use only.

No Customer Information

Only one interface is used — for admin within the store. There is no need for customers to provide email, names, phone numbers, or similar personal details.

Internal Use Only

There is only one interface designed exclusively for administrative use within the store — not exposed to the public or customers.

Scope

Because the system is used only by owners and staff on-site, there is no requirement for customers to provide personal identification details.
